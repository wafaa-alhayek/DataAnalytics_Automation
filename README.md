# DataAnalytics_Automation

SQL, scripts and sample projects for Describe's data work.

| Folder | What it is |
|---|---|
| [`ngo-indicator-dashboard/`](ngo-indicator-dashboard/) | Sample NGO indicator dashboard: BigQuery + Looker Studio, English and Arabic. Programme figures are sample data; country context is World Bank public data. |
| [`arabic-survey-coding/`](arabic-survey-coding/) | Gemini on Vertex AI tags open-ended Arabic survey answers into themes, sentiment and follow-up flags, scored against a human coder, loaded into BigQuery. Answers are synthetic. |
